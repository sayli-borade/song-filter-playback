# 🎵 YouTube Music UI (Case Study)

## 📌 Description
This project is a simple YouTube Music style web application built using HTML, CSS, and JavaScript. It allows users to view songs by category, search songs, and play audio by clicking on a song.

---

## 🚀 Features
- 🎧 Play song on click
- 🔍 Search songs dynamically
- 🎵 Filter songs by category (Feel Good, Workout, etc.)
- 🖼 Display song images
- 🎯 Highlight currently playing song

---

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

---

## 📂 Project Structure
case_study/ │── index.html │── style.css │── script.js │── images/ │── songs/

---

## ▶️ How It Works
- Song data is stored in a JavaScript object (`musicData`)
- When a category is selected, songs are displayed dynamically
- Clicking on a song:
  - plays audio using the `<audio>` element
  - updates "Now Playing" text
  - highlights the selected song

---

## 🎯 Main Function
- `showSongs(category)` → Displays songs based on selected category

---

## 📌 Conclusion
This project demonstrates DOM manipulation, event handling, and audio playback using JavaScript.
